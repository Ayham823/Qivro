# Security Policy

## Public Repository Scope

This repository contains presentation documentation and screenshots only. It
must never contain live credentials, environment files, certificates, database
exports, backups, customer data, provider responses, or production logs.

## Reporting

Please report a suspected security issue privately through GitHub's security
advisory feature for this repository. Do not open a public issue containing
credentials, personal data, or exploit details.

## Source Repository Release Gate

Qivro source repositories are reviewed independently. A repository is not made
public until both its current tree and reachable Git history have been scanned,
affected credentials have been rotated, and generated or private artifacts have
been removed from tracking.
