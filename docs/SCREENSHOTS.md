# Screenshot and Data Policy

The screenshots in this repository are product evidence captured from a local
Qivro environment.

## Rules

- Use deterministic seed users and properties only.
- Do not capture production or customer data.
- Do not expose tokens, environment files, provider dashboards, private URLs,
  browser extensions, personal messages, or operating-system notifications.
- Keep screenshots at a consistent desktop viewport for the main README.
- Use the English interface for published screenshots and demo videos.
- Capture mobile evidence separately when it adds engineering value.
- Replace a screenshot when it no longer matches the current implementation.

## Current Set

| File | Purpose |
| --- | --- |
| `home.png` | Product identity and unified search experience |
| `listings.png` | Results, filters, cards, and pagination hierarchy |
| `property-details.png` | Property information and action hierarchy |
| `dashboard.png` | Authenticated owner workspace |

The screenshots demonstrate application behavior and layout. They do not claim
live users, live inventory, connected payments, or a public production environment.
